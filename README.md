# Guillaume Aversa

Infrastructure & Ops engineer based in Lyon, France.

I spend my days keeping production boring and predictable: cloud infrastructure,
Kubernetes, observability and automation. Most of what I ship is the glue —
Bash, Terraform and CI pipelines — that turns servers into something you don't
have to think about.

### Stack

- **Cloud** — Azure · AWS · GCP · Scaleway · Cloudflare
- **Orchestration** — Kubernetes · Docker · Helm
- **IaC & automation** — Terraform · Ansible · Bash
- **Data** — MySQL · PostgreSQL
- **Observability** — Grafana · Zabbix · Nagios · Uptime Kuma
- **Security** — CrowdSec · WAF · server hardening
